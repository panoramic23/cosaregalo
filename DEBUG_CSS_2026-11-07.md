# Debug CSS / header / menu — 7 novembre 2026

## Problemi identificati

1. **Versioni miste HTML + CSS/JS.** `server.mjs` distribuiva HTML con `no-cache` ma `/assets/style.css` e `/assets/site.js` con `public, max-age=3600`. Una visita dopo il deploy poteva mostrare un menu appena generato e uno stylesheet vecchio per fino a un'ora, producendo voci di grandezze diverse e l'header blu ancora sticky.
2. **Font heading non normalizzati.** I tag `h4`, `h5`, `h6` avevano il grassetto predefinito del browser. Alcuni `h3` conservavano peso 600 e dichiarazioni shorthand precedenti; il layout precedente aveva persino applicato un contorno extra agli H3.
3. **Tipografia menu contraddittoria.** Le regole storiche di `.nav-menu a` avevano pesi 900 e font-size 12/11/13/14; le regole successive tentavano di prevalere con selettori diversi. È stata normalizzata la dimensione del testo sia su ancore che su bottoni/dropdown.
4. **CSS legacy mobile.** Rimossa la vecchia `top:177px` e confermata la navigazione mobile ancorata alla sola barra bianca.

## Correzioni applicate

- `server.mjs`: ogni HTML contiene `style.css?v=<assetRevision>` e `site.js?v=<assetRevision>`; gli asset CSS/JS richiedono revalidazione, HTML di staging `no-store`. `/health` contiene `uiRelease: "css-debug-20261107"` e `assetRevision` per verificare se è realmente installata la nuova release.
- `assets/style.css`: soltanto `.nav-bar` è `position:sticky;top:0`; `.top-header` e `.announcement` sono `position:relative`. Tutte le voci del primo livello hanno Arial 14px / peso 700 su desktop, 15px su mobile, label e button inclusi. Icone 17px, label non vanno a capo.
- H1/H2: Baloo 2 800. H3/H4/H5/H6: Baloo 2 500, `-webkit-text-stroke:0`, anche se regole precedenti provano a renderli più spessi.
- `tests/ui-css-regression.test.mjs`: nuovi controlli di regressione del CSS e del server. Eseguire `npm test` nel repository con Node >= 20.

## Come verificare SiteGround

1. Eseguire deploy dal ramo `main` e riavviare l'app Node.
2. Aprire `https://micheleg58.sg-host.com/health`. Deve mostrare `"uiRelease":"css-debug-20261107"`.
3. Aprire la homepage: nel sorgente HTML il link CSS deve contenere `?v=` e uno stamp che corrisponde ad `assetRevision`. In DevTools → Network, `style.css` deve avere `Cache-Control: no-cache, must-revalidate`.
4. Scorrere la pagina: la barra blu con logo e ricerca deve scomparire, mentre la sola barra bianca navigazione resta a `top:0`.
5. Confrontare computed styles di `Categorie`, `Idee regalo`, `Trova un regalo`, `Guide`, `Confronti`, `Super offerte`: i label desktop devono essere 14px/700. I titoli H3–H6 devono avere `font-weight:500`.
6. Provare i dropdown sia desktop che mobile e passare da home a una guida, una tipologia e una pagina Esplora.
